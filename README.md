# D题：科学图表原生重绘与完整论文工程

**先看 `figures/P01.png`—`P06.png` 或 `论文联合诊断图册.pdf`。**
这次修改的是坐标轴上的数据编码与图形对象，不是在旧图片外面套卡片。
全部图由CSV/JSON/DEM经Python重新绘制；没有加载旧实验图进行裁剪、贴图或加框。

## 使用哪一份内容

- `overleaf/`：完整论文工程，main.tex默认使用29幅同名重绘图。可直接使用对应的独立ZIP。
- `figures/`：163幅独立中文图以及6幅多面板组图；每幅均为PNG、PDF、SVG三种格式。
- `plot_data/Fxxx.json`：每幅图的原始来源哈希、实际绘图变量与统计/模型诊断含义。
- `viz/`：本次原生图表代码；样式、渲染、补充诊断、矢量组合分开维护。
- `experiment/`：上一版闭环求解工程的完整冻结副本，含原始数据、清洗数据、Q1—Q4源码、提交工作簿及验证日志。
  其中旧的 `results/figures/` 只为保留历史证据；论文采用的是本总包根目录 `figures/` 下的新图。
- `audit/`：本轮数据追溯、绘图一致性、原文转写一致性、重新编译与文件清单。
- `论文图表重绘说明.md`：图形选择、含义边界和对参考图的科学性取舍。

## 本次不做的事情

## 重绘与核验

已装依赖时，从任意工作目录执行：

```bash
python /实际路径/D_scientific_redesign/rebuild_publication.py
```

在项目目录首次安装后运行：

```bash
python -m pip install -r requirements.txt
python rebuild_publication.py
```

默认读取已计算结果，依次完成：163幅独立图 → 逐图数据核验 → 6幅原生矢量组图 → Overleaf同名替换。
不要求联网，也不再次搜索最优调度。Windows与Linux/macOS启动脚本见同目录。

完整原始数据求解与原论文物理验证仍可执行：

```bash
python experiment/run_all.py --check-reference
python experiment/validate_submission.py
```

或 `python rebuild_publication.py --recompute` 先调用原求解入口再重画；这一步会重新生成原实验目录中的结果。
当前冻结哈希是严格原版本基准；自行改参数或跨依赖版本造成数值变化时，程序应报告不一致，而不是静默宣称同一结果。

本地同时编译论文：

```bash
python rebuild_publication.py --compile
```

需要本机有latexmk/XeLaTeX。使用Overleaf则只上传独立工程ZIP，不需要运行Python。

## 中文字体与矢量文件

实测Python3.13.5，依赖锁定于requirements.txt。绘图系统需有思源黑体、Noto Sans CJK、微软雅黑或黑体之一。
程序找不到中文字体时明确报错，不生成缺字图。CairoSVG在部分系统需安装Cairo运行库。
本包不含任何字体文件。PDF/SVG中的字形和线条转为矢量路径，不需要向Overleaf上传字体；
地图里的DEM背景自然是源高程栅格，不应误称整幅图纯矢量或误当作旧实验图截图。
